# 公開GHCRの配布判断（初心者向け）

## 現在の結論

2026年11月5日時点で、**モデル4点を同梱した公開GHCRイメージの配布は未承認です。**

RirukaChan型の「ComfyUI・Worker・Workflow・モデル同梱」の目標は維持します。RunPod Network Volumeへのモデル別置きには変更しません。

## 既に進んだこと

- TenStripは10ErosにLTX-2ライセンスが適用されると説明しています。
- LTX 2.3の公式ライセンス全文とAttachment Aを公開キットに収録しました。
- Gemma 3の公式規約を照合するため2026-04-01版の文書スナップショットを収録しました。
- Gemmaに必須のNotice文面を収録しました。
- ComfyUIのGPL-3.0全文を収録しました。
- 模擬ウェイトの複数OCIレイヤー化・GHCR公開・Pull・ネットワーク無しの復元テストは成功しています。

## なぜ公開可能と断言していないのか

LTX-2 §3(a) と Gemma §3.1は、利用制限を**拘束力ある契約条件**として受領者に適用することを求めています。匿名Pullが可能な公開GHCRのREADMEや実行時の確認画面だけでは、受領前の同意が成立するとは限りません。

また、LTX §7の制裁・輸出管理条件により、禁止された地域・受領者へ配布してはいけません。注意書きはアクセス制御ではありません。

LTXの規約が取り込むAcceptable Use Policyは性的に露骨なコンテンツなどの禁止事項も定めています。**10Erosの技術的な生成可能性と、利用規約上の許容範囲は別問題です。**

## 最短コースと独立コース

- **公開GHCRコース**は、ライセンス条件の履行方法を確認できてから提供します。
- **個別GHCRコース**は、各人が正規配布元から取得して自己利用イメージを作る方式ですが、それでも規約の適用が消えるわけではありません。
